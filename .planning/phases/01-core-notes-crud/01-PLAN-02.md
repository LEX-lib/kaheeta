|----------|-------------|
| user input → Tiptap editor | Rich text content entered by the user; Tiptap renders it as ProseMirror DOM nodes |
| editor content → PocketBase write | Serialised as JSON string (editor.getJSON()), not HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering (XSS) | Tiptap Link extension | mitigate | Link.configure({ protocols: ['http', 'https'] }) — blocks javascript: hrefs and other non-http schemes; editor stores JSON not HTML so there is no HTML round-trip XSS vector |
| T-02-02 | Tampering (XSS) | ProseMirror rendered output | accept | Body stored as ProseMirror JSON (editor.getJSON()), not HTML; Vue template renders text nodes with automatic escaping; risk is low in a personal single-user journal |
| T-02-03 | Denial of Service | Auto-save debounce | accept | 1000ms debounce with flush-on-close prevents excessive PocketBase writes; no per-user rate limit needed at this scale |
| T-02-SC | Tampering | npm install (Tiptap packages) | mitigate | All 8 packages slopcheck [OK] per RESEARCH.md; no postinstall scripts verified via npm registry 2026-06-30; install command in Task 1 is exact per RESEARCH.md |
