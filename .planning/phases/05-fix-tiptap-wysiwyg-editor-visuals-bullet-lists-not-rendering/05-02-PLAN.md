<objective>
Restore correct editor visuals in `wallecx-overrides.css`: visible list markers with indentation
(bullets + numbers + nesting), consistent heading/paragraph spacing, and a globally-visible amber
text caret. Implements CONTEXT decisions D-02 (minimal typography correctness) and D-03 (amber
caret in both themes).

Purpose: Tailwind v4 preflight (`@import "tailwindcss"` in base.css) resets `list-style`, list
padding, and block margins on `ul`/`ol`/`p`/headings. The editor CSS block (§"Notes — ProseMirror
editor styles", ~lines 242-331) currently styles heading sizes and links but has NO list rules,
NO block margins, and sets `caret-color` ONLY under `.my-app-dark` — so in light mode the caret
can be invisible against the light surface. This plan is pure CSS extending the existing block in
place; it touches no Vue/TS and no data model.

Output: New list + spacing + caret rules appended to / interleaved in the existing ProseMirror
CSS block, using the established global-base + dark-remap convention and existing `--color-*`
design tokens.
</objective>
