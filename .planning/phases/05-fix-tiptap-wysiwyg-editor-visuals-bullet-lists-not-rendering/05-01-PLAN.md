<objective>
Add numbered-list (ordered-list) support to the Tiptap note editor and make ordered-list
content survive snippet generation. Implements CONTEXT decision D-01 (bullets + numbered +
nesting).

Purpose: Bullets already render as nodes but numbered lists are not a registered node type,
so `toggleOrderedList` is unavailable and any ordered-list content would be dropped from the
encrypted snippet. Registering `@tiptap/extension-ordered-list` in BOTH the live editor
(NoteEditor.vue) AND the snippet generator (currently inline in ManageNote.vue's `saveFn`)
keeps the two extension arrays in sync. Extracting the snippet generation into a pure module
gives us the one behavioral guarantee that IS unit-testable in a CSS-heavy phase.

Output: `@tiptap/extension-ordered-list` dependency, an OrderedList extension + numbered-list
toolbar button in NoteEditor.vue, a pure `noteSnippet.ts` helper with Vitest coverage, and
ManageNote.vue rewired to call it.
</objective>
