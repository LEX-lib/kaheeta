# Requirements: Kaheeta Notes — v1.0 (ARCHIVED)

> **Archived 2026-07-02 at v1.0 milestone close.** All v1 requirements delivered across
> Phases 1–5. This is a historical snapshot; the active project starts a fresh REQUIREMENTS.md
> at the next milestone (`/gsd:new-milestone`).

**Defined:** 2026-06-30
**Shipped:** 2026-07-02 (v1.0 "Notes")
**Core Value:** Users can capture private, richly-formatted notes knowing the server stores only ciphertext — their content is readable only on their own device.

## v1 Requirements — all delivered

### Notes Management

- [x] **NOTE-01**: User can create a note with a title and a rich-text body (Tiptap WYSIWYG editor) — Phase 1
- [x] **NOTE-02**: User can open and edit an existing note — Phase 1
- [x] **NOTE-03**: User can delete a note with a confirmation dialog — Phase 1
- [~] **NOTE-04**: ~~Note changes auto-save — no explicit save button required~~ **Superseded by EDIT-01 (Phase 4)** — auto-save replaced with manual save.

### Editing (Phase 4 — post-v1 enhancement)

- [x] **EDIT-01**: Manual save replaces auto-save — explicit Save control + visible dirty indicator; edits not written on every keystroke (supersedes NOTE-04) — Phase 4
- [x] **EDIT-02**: Unsaved edits persisted to localStorage as a per-note encrypted draft and recovered after refresh/close — Phase 4

### Encryption

- [x] **ENC-01**: Note body encrypted client-side (AES-GCM, 256-bit) before writing to PocketBase — Phase 2
- [x] **ENC-02**: Encryption key derived from user session via PBKDF2 + per-user salt — no extra password — Phase 2
- [x] **ENC-03**: Decryption in-browser on read — body never sent in plaintext — Phase 2

### Notes List

- [x] **LIST-01**: Notes displayed in a flat list sorted by last-modified (newest first) — Phase 1
- [x] **LIST-02**: Each list item shows title, created date, and a plaintext preview snippet — Phase 1
- [x] **LIST-03**: User can search notes by title (client-side, instant) — Phase 3

### Navigation

- [x] **NAV-01**: Notes section accessible from the main wallet navigation (KaheetaNavBar) — Phase 1

### Editor quality (Phase 5 — post-v1 polish)

- [x] Editor renders correctly across light/dark: bullet/numbered/nested lists, heading/paragraph spacing, always-visible caret — Phase 5 (hardened NOTE-01/NOTE-02; decisions D-01/D-02/D-03). No formal REQ ID — editor-polish/bugfix phase.

## Out of Scope (unchanged)

| Feature | Reason |
|---------|--------|
| Note sharing | Personal journal only — explicitly excluded forever |
| Collaborative/real-time editing | Personal-only; architecture would need full rework |
| Server-side encryption | Client-side AES-GCM is sufficient; keeps backend simple |
| OAuth / separate encryption password | User session is the key derivation source; no second password |
| Mobile app (native) | Web PWA only |
